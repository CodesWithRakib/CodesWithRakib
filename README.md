## 🚀 About Me

I'm a **Frontend Developer at SOFOF Tech**, focused on building modern, scalable, maintainable, and user-friendly web applications. I work primarily with **React, Next.js, TypeScript, and the modern JavaScript ecosystem**, while continuously expanding my backend and software engineering skills.

My work involves developing real-world SaaS applications, implementing responsive interfaces from Figma designs, integrating REST APIs, building role-based dashboards, and working with authentication, data-driven features, and complex business workflows.

I'm actively growing toward full-stack engineering by working with **NestJS, Node.js, PostgreSQL, MongoDB, and modern backend architecture**.

- 💼 Currently working as a Frontend Developer at SOFOF Tech.
- ⚛️ Building applications with React, Next.js, TypeScript, and Redux Toolkit.
- 🏗️ Working on full-stack SaaS projects with real business requirements.
- 🔌 Integrating APIs, authentication flows, permissions, and real-time features.
- 🗄️ Expanding my knowledge of backend development, database design, and API architecture.
- 🧠 Learning software design principles, system design, testing, and performance optimization.
- 📚 Focused on understanding fundamentals, writing maintainable code, and solving real-world problems.
- 🎯 Long-term goal: become a strong Full-Stack Software Engineer.

> I believe good software is not just about making things work. It's about building solutions that are understandable, maintainable, secure, and useful to real users.

## 🚀 Featured Projects

I'm building and improving real-world SaaS applications focused on practical business problems, scalable architecture, and maintainable code.

### 🎓 [OgroniEdu — Tutoring Platform](https://github.com/CodesWithRakib/ogroniedu)

A tutoring platform designed for students, guardians, tutors, and administrators in Bangladesh.

- Role-based dashboards and access control
- Tutoring workflows and scheduling
- API-driven features and real-time notifications
- Responsive, bilingual user experiences
- Modular frontend and backend architecture

**Tech Stack:** Next.js, React, TypeScript, NestJS, PostgreSQL, TypeORM

### 🚚 [Dhruto — Courier & Logistics SaaS](https://github.com/CodesWithRakib/dhruto)

A logistics management platform focused on merchant operations and courier delivery workflows.

- Shipment and delivery management
- Cash-on-delivery (COD) settlement workflows
- Return-to-origin (RTO) handling
- Merchant dashboard and API integration
- Queue-based background processing architecture

**Tech Stack:** Next.js 16, TypeScript, Redux Toolkit, RTK Query, NestJS, PostgreSQL, TypeORM, Redis, BullMQ

### 🛒 [Gramer Bazar — Local Marketplace SaaS](https://github.com/CodesWithRakib/gramer-bazar-saas)

A local marketplace platform designed to connect buyers, sellers, and delivery partners in Bangladesh.

- Multi-role marketplace workflows
- Product catalogs, categories, and variants
- Search, filtering, sorting, and pagination
- Database-driven product and marketplace data
- Bilingual user experience and responsive interfaces
- Monorepo-based frontend and backend architecture

**Tech Stack:** Next.js, TypeScript, NestJS, PostgreSQL, TypeORM
